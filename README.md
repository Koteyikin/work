Для того чтобы запустить проект нужно:

1)Скачать проект с гита с помощью PHPSTORM
	1.1)Сверху справа с помощью кнопки Clone repository
	1.2)В открывшимся окно вставить ссылку на репозиторий https://github.com/Koteyikin/work.git

2)На проект установить композер с помощью  команды "composer install"
	2.1)Смотите куда устанавливаетее composer нужно в cвоей проект 
	2.2)Обычно если вы устанавливаете проект с помщью PHPstorm путь будет примерно такой "C:\Users\имя_пользователя\PhpstormProjects\название_проекта"

3)С гугл диска(https://drive.google.com/file/d/1DQpc3DWptpYhOWtjbO0j-3yzyMDCktvm/view?usp=sharing) нужно скаачать архив с названием phpmyadmin её требуется распоковать на какой нибудь диск и запустить Ospanel

4)Запустив Ospanel нужно открыть phpmyadmin в нем создать базу данных c названием work 

5)После в проекте в командной строке нужно написать php artisan migrate 

6)Так же по желанию можно просписать php artisan DB:seed для заполнения таблиц проектов и задач

7)После прописать php artisan serve и перейти по ссылке которая выдала командная строка 

8)Как зайдете на сайт будет страничка регистрации, после регистрации вас должно перекинуть на страничку со всем функционалом который смог реализовать, если этого не произойдет и вас перекидыват на просто страничку с белым фоном, то в домене пропишите /test
